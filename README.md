# Victoria Crest website

A responsive, conversion-led Next.js website for Victoria Crest, designed to drive visitors to the official Oddle shop.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

All primary product and order calls-to-action link to:
`https://victoriacrest.oddle.me/en_MY`
